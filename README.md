# 🚀 Featured Projects

## 🏠 DormDrop

### Campus Marketplace for Students

> **Giving campus essentials a second life.**

### 🎯 Problem

Students often have useful books, electronics, lab equipment and hostel essentials they no longer need, while other students from the same college are searching for those exact items.

**DormDrop connects students within the same campus to buy and sell pre-owned items easily and affordably.**

### ✨ Key Features

- 🛍️ Campus-exclusive marketplace
- 📦 Create and manage product listings
- 🔎 Search and category-based discovery
- 🔐 Student authentication
- ❤️ Save useful listings
- 📱 Responsive mobile-first interface
- 👤 Student profiles and listing management
- 💬 Buyer-seller interaction

### ⚙️ Tech Stack

`React` `TypeScript` `Supabase` `PostgreSQL` `Tailwind CSS` `REST APIs`

**Status:** 🟢 Active Development

## 😊 Mood Journal

### Mood Tracking & Analytics Platform

> **Understand emotions through data.**

### 🎯 Problem

Traditional journals allow people to record their thoughts but provide little insight into how their moods change over time.

**Mood Journal combines journaling with mood tracking and visual analytics to help users understand emotional patterns.**

### ✨ Key Features

- 😊 Daily mood logging
- 📝 Personal journal entries
- 📊 Mood analytics dashboard
- 🗓️ Calendar mood heatmap
- 📈 Interactive charts
- 📚 Journal history
- 📱 Responsive interface

### ⚙️ Tech Stack

`Python` `Flask` `SQLite` `HTML` `CSS` `JavaScript` `Chart.js`

**Status:** 🟣 Version 1 Completed
